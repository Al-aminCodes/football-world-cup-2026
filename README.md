## 📖 About The Project

**FIFA World Cup 2026 Landing Page** is a modern, responsive web application engineered to showcase the grand scale of the 48-nation football tournament across North America. It acts as an interactive central platform featuring real-time booking channels, multi-city venue guides, and scheduled fixture tables from the opening whistle down to the finals.

### Key Features
* 🎫 **Ticketing Core & Live Stats:** Clean data counters tracking real-time metrics including live coverage hours, user satisfaction, and seat bookings.
* 🏟️ **Host Venue Portal:** A component system breaking down individual stadium specs, transit configurations, and total seat availability per host city.
* 📅 **Fixtures Ledger Component:** A highly organized data matrix managing times, group stages, venue tracking, and bracket timelines for global matchups.
* ⚡ **Optimized Fluid UI:** Tailored grid layouts maximizing cross-platform visibility from dense desktop layouts down to small-screen mobile devices.
